# 篮球战术板 · 使用说明

一个网页版战术板：摆球员、画路线、分帧串成动画，最后导出图片或 GIF 发给队员。

---

## 一、怎么打开

- 双击项目里的 **index.html**，用 Chrome 或 Edge 打开即可，不用安装任何东西。
- 打开后已经摆好一套半场 5 攻 5 守的阵型，可以直接开始改。
- **推荐用电脑（或平板）画战术**：屏幕大、有鼠标右键，画路线和微调都最顺手。手机适合随时查看、播放和做小改动。
- 鼠标和触屏都能用（平板上手指拖动＝鼠标拖动）。
- **只有导出 GIF 需要联网**（要临时下载一个动图编码库），其他功能断网也能用。

## 二、界面分区

| 位置 | 内容 |
|---|---|
| 顶栏 | 战术名称输入框、保存、加载、导出、设置 ⚙️ |
| 左侧工具栏 | 半场/全场切换、双方人数、球员操作面板、箭头颜色、帧时长、快捷键提示 |
| 中间 | 球场画布，所有编辑都在这里做 |
| 画布下方（画路线 / 选中时才出现） | 操作条：完成 / 退一点 / 删除 / 取消 |
| 底部第一行 | 播放控制：上一帧 / 播放暂停 / 下一帧 / 停止、进度条、倍速 |
| 底部第二行 | 本帧字幕输入框 |
| 底部第三行 | 帧缩略图列表，末尾的 **+** 用来加帧 |

### 手机 / 窄屏上的界面

屏幕变窄时布局会自动换一套，功能一个都不少：

| 变化 | 说明 |
|---|---|
| 工具栏挪到球场**下方** | 变成一条**横向滑动**的工具带，手指左右划就能找到人数、颜色、时长等设置 |
| 顶栏按钮只留图标 | 💾 📂 📤 ⚙️ 照常点，文字标签隐藏是为了省地方 |
| 帧缩略图上的 ⧉ 复制 / ✕ 删除**一直显示** | 触屏没有「鼠标悬停」，所以两个按钮直接摆在缩略图右上角 |
| 工具栏里的「🖱 选择」隐藏 | 用操作条的「✕ 取消」就能回到选择状态，作用一样 |
| 快捷键提示隐藏 | 手机用不到 |
| 球场自动缩放 | 不管多小的屏，球场都完整显示、比例不变，只是会小一些 |

**手机请保持竖屏。** 半场接近正方形，横过来以后顶栏和底部几行会把高度吃掉，留给球场的地方反而更少，画出来更小。竖屏才是手机上最大的球场。

**横屏 / 很矮的窗口**（比如电脑窗口拉得很扁）：工具栏回到左侧变窄，操作条出现时会**顶替字幕那一行**，避免球场被挤得突然变小；收起操作条后字幕行自动回来。

## 三、画一个战术的完整流程

1. **起名**：在顶栏输入战术名，例如「边线球 - 双掩护」。
2. **摆位**：拖动球员到起始位置；**双击某个球员**把球交给他（触屏改为选中球员后点面板里的 **🏀 持球**）。
3. **画路线**：单击选中球员 → 左侧出现「球员操作」面板 → 点 跑位 / 传球 / 运球 / 挡拆 → 在球场上**左键点出转向点**，**右键点终点**结束。
4. **写字幕**：在底部字幕栏写这一步要讲的话，例如「1 号借 5 号掩护切出接球」。
5. **加下一帧**：点底部的 **+**。新帧会自动把球员放到上一步路线的终点，传球后的球权也会自动交给接球人。
6. 重复第 2～5 步，把战术拆成若干帧。
7. **检查**：点 ▶ 播放，看整套跑位是否顺畅。
8. **交付**：💾 保存 存一份工程文件，📤 导出 出 PNG 或 GIF。

## 四、球员和球

- 左侧「进攻方 / 防守方」人数可填 0～5，改完立刻生效，**只影响当前这一帧**。
- 拖动球员移动；**双击球员**切换持球（触屏用面板里的 🏀 持球 / ❌ 放下球）；球本身也能单独拖走（拖走即视为脱手）。
- **右键点球员**删除他（相关路线一起删）；也可以选中后按 `Del`，触屏点操作条的 **🗑 删除**。
- ⚙️ 设置里可以改双方球衣号码或名称，用逗号分隔，例如 `PG,SG,SF,PF,C`，点「应用」生效（**只改当前帧**的球员）。
- 规则限制（按钮会自动变灰提示）：只有进攻方能持球；**持球人**只能传球或运球，**无球人**只能跑位或挡拆；正在接球的人本帧不能再行动。

## 五、四种路线

| 路线 | 样子 | 画法 |
|---|---|---|
| 跑位 | 实线 + 三角箭头 | 左键加转向点，右键定终点，可弯折 |
| 传球 | 虚线 + 三角箭头 | 点击队友、篮筐或队友路线的终点作为目标；右键取消 |
| 运球 | 波浪线 + 三角箭头 | 左键加转向点，右键定终点 |
| 挡拆 | 实线 + 末端横杠 | 左键加转向点，右键定终点 |

**手机 / 平板上没有右键，改用屏幕上的操作条：**

开始画路线后，播放控制条上方会自动出现一条按钮：

| 按钮 | 作用 |
|---|---|
| ✅ 完成 | 把**最后一个点**作为终点，路线立即画好（等于电脑的右键） |
| ↩ 退一点 | 删掉上一个点，重新点过 |
| ✕ 取消 | 放弃这条路线，回到选择状态（等于电脑的 Esc） |

还没点第一个点时，「完成」和「退一点」是灰的，点一下球场就亮了。

选中一条路线或一个球员时，同一条会变成 **🗑 删除** 和 **✕ 取消选中**（等于电脑的右键删除 / Del 键）。

所以触屏画法是：**选中球员 → 点动作按钮 → 在球场上依次点出各个点 → 点「✅ 完成」**。最后点的那一下就是终点，不用额外操作。这条操作条在电脑上同样显示，用鼠标的人也可以直接点「完成」，不必记右键。

**改路线**（先回到「🖱 选择」，手机上点操作条的「✕ 取消」）：

- 拖**实心终点**改长短方向；拖**空心控制点**改弯曲形状。
- **双击路线**可在该处插一个控制点，再拖它微调（这一条只有鼠标能做，触屏上直接拖已有的空心控制点即可）。
- 起点跟着球员走，不能单独拖；想改起点就拖球员。
- **右键点路线**删除它。
- 选中一条路线后再改「箭头颜色」，只改这一条；没选中时改的是之后新画的默认色。

## 六、帧（战术的分解步骤）

| 操作 | 做法 |
|---|---|
| 新增帧 | 点列表末尾 **+**，插在当前帧后面 |
| 复制帧 | **双击**某个帧缩略图；触屏点缩略图右上角的 ⧉ |
| 删除帧 | 点缩略图右上角 ✕（至少保留 1 帧） |
| 切换帧 | 点缩略图，或按 `←` `→` |
| 改停留时长 | 左侧「持续时间(秒)」，0.3～5 秒，默认 1.5 秒 |

写过字幕的帧，缩略图左上角会有一个红色「字」标记，鼠标停上去能看到字幕全文。

## 七、字幕与战术名称

- **字幕**：每帧独立，最多 80 字，显示在球场下方，**会一起画进 PNG 和 GIF**。右侧 ✕ 清空本帧字幕。
- **战术名称**：最多 40 字，显示在球场左上角的红色标签里，**同样会画进导出图**；它还决定导出文件名，并随工程文件一起保存。

## 八、播放

- ▶ 播放 / ⏸ 暂停，⏮ 上一帧，⏭ 下一帧，⏹ 停止并回到开头。
- 按住进度条拖动，可以直接跳到任意一帧。
- 倍速 0.25×～2×，讲解时用 0.5× 更清楚。
- 播到最后一帧会**自动循环**回第一帧；至少要有 2 帧才能播放。

## 九、保存与导出

| 按钮 | 结果 | 说明 |
|---|---|---|
| 💾 保存 | `战术名.json` | 工程文件，以后能继续编辑 |
| 📂 加载 | — | 选一个之前保存的 .json 打开 |
| 📤 导出 → 当前帧 PNG | 一张静图 | 适合放进战术手册；高分屏上导出的图更清晰 |
| 📤 导出 → 全部帧 PNG | 每帧一张 | 浏览器可能询问「允许下载多个文件」，点允许 |
| 📤 导出 → GIF 动图 | `战术名.gif` | 15 帧/秒，可直接发微信群；需要联网、至少 2 帧 |

GIF 很长时（超过约 150 张画面）会自动降低采样密度来保证导出成功，**动画总时长不变**，只是略微没那么顺滑。

## 十、快捷键

| 按键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` `→` | 上一帧 / 下一帧 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Del` | 删除选中的球员或路线 |
| `Esc` | 取消正在画的路线、取消选中，回到「🖱 选择」 |
| `Ctrl+S` | 保存工程文件 |
| `1` `2` `3` `4` `5` | 选择 / 跑位 / 传球 / 运球 / 挡拆 |

在输入框里打字时，快捷键不会误触发。连续输入一段字幕算**一步**撤销，不会一个字一个字地退。

## 十一、常见问题

**手机 / 平板上没有右键，怎么定终点、怎么删除？**
用屏幕上的操作条：画路线时点「✅ 完成」定终点、「↩ 退一点」回退、「✕ 取消」放弃；选中路线或球员后点「🗑 删除」。详见第五节。

**手机上球场太小、工具栏找不到？**
竖屏时工具栏在球场下方，是一条可以**左右滑动**的工具带，手指左右划就能找到人数、颜色、时长等设置。球场始终完整显示、不会被裁掉。**手机保持竖屏就好，横过来反而更小**；想要大画布请用电脑或平板。

**半场和全场是什么关系？**
两套**各自独立**的战术，来回切换不会互相覆盖，但**保存 JSON 时只保存当前这一套**。两边都画了内容，就切过去分别保存成两个文件。全场是横向显示的，球员号码已经转正，不会躺倒。

**刷新页面后战术没了？**
是的，页面不会自动恢复上次的编辑。离开前请先 💾 保存，下次用 📂 加载 打开那个 .json。

**导出 GIF 提示「库未加载」？**
连上网后刷新页面再导出。这个库是从网上临时加载的。

**全部帧 PNG 只下载到一张？**
浏览器拦截了批量下载，在地址栏右侧的提示里选择「允许」，再导出一次。

**场地尺寸准吗？**
按 FIBA 官方规则绘制：全场 28×15 米、三分线 6.75 米、罚球区 4.9×5.8 米、合理冲撞区 1.25 米，含罚球区分位线和边线发球标记。

**画错了怎么办？**
`Ctrl+Z` 撤销，拖动、画线、删除、改人数、写字幕都能退回。
